Dirb is a web content scanner used to discover hidden files, directories, and pages on web servers. It is commonly included in penetration testing distributions like Kali Linux. Below are the steps to use Dirb effectively.
>>dirb http://example.com/

Tools like Gobuster or Dirb can be used to perform directory brute-forcing. This method systematically attempts to discover pages that are not linked in the main site navigation but still respond to HTTP requests. In the case of FakeBank:
>>gobuster dir -u http://fakebank.thm -w wordlist.txt
